# JugaBet — Fan of Cards playable

Портретная мини-игра (пропорции фрейма Figma 1089×1920), концепт «Fan of Cards (Blind Choice)» с тремя попытками:
веер из 5 карт рубашкой вверх «дышит», уменьшенная рука подсказывает тап, от пальца на каждом нажатии расходятся кольца.
Под веером три слота-индикатора, следующий слот подсвечивается.
1. Первая карта серая: «BONO: 0 GIROS GRATIS», глухой толчок и пыль, заголовок «¡Prueba otra vez!». Карта улетает в первый слот, в веер сдаётся новая карта.
2. Вторая карта золотая, но на половину: «BONO: 50% DEL PREMIO», искры, заголовок «¡La suerte está cerca!». Карта улетает во второй слот.
3. Третья карта — полный приз: вспышка и световая дуга (canvas, без картинки), заголовок «¡Felicidades! ¡Ganaste!». Все три слота по очереди переворачиваются в золотые «125 giros gratis», затем стекаются в плашку «TU BONO: 125 GIROS GRATIS», после неё появляется кнопка «RECLAMAR BONO».

Без фреймворков: HTML + CSS + JS (Web Animations API).

## Сборка

```bash
npm install
npm run build                                   # -> dist/index.html (один файл, ~200 KB)
node tools/build.mjs --amount=125 --unit="giros gratis" --url=https://landing.example
```

Параметры кампании и все тексты (испанский) лежат в [src/config.js](src/config.js): `bonusAmount`, `bonusUnit`, `clickUrl`, `locale`, `text` (заголовки после 1-й и 2-й карты, надписи на серой и половинной картах).
Флаги `--amount`, `--unit`, `--url` переопределяют их при сборке. Длинные тексты автоматически ужимаются по ширине (`data-max` в разметке).

## Разработка

```bash
npm run dev            # http://localhost:8765/src/index.html
```

Для QA: `?pick=0..4` сам выбирает эту карту в каждом раунде, `?round=2` или `?round=3` начинает со второй или третьей попытки (предыдущие слоты уже заполнены), `&hold=1` останавливает игру на последней раскрытой карте с золотыми слотами, без финала с кнопкой.
С `?pick=` в консоли доступна `__swirlAt(0..1)` — рисует световую дугу вокруг карты в заданный момент её жизни.

## Структура

- `figma-src/` — исходники из Figma (как есть)
- `tools/prepare_assets.py` — нарезка и сжатие в WebP. Лицевая сторона карты выпрямляется (в Figma она наклонена на 11,38°), из неё вырезается только золотая рамка: сияющий фон и надпись «BONO: 5000 MXN» были нарисованы в картинке, теперь фон собран в CSS, а сумма — живой текст
- `src/` — игра; `src/ad.js` — адаптер сетей: MRAID (AppLovin, Unity, Vungle…), ironSource `dapi`, Mintegral, Google `ExitApi`, Meta `FbPlayableAd`, иначе `window.open`
- `dist/index.html` — готовый файл для загрузки в сеть
