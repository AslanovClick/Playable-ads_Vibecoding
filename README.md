# EVA AI — плейабл «Find Your Type»

Портретная мини-игра в пропорциях фрейма Figma (1080×1920): выбор стиля, затем одной из четырёх девушек, и знакомство с ней. Без фреймворков: HTML + CSS + JS (Web Animations API, WebAudio), сборка в один `dist/index.html` до 5 МБ.

1. **Шаг 1 · Choose your style.** Две карточки (картинки из Figma, без видео): Jade в стилях Realistic и Anime. Пока ничего не выбрано, карточки по очереди мягко пульсируют, кнопка «Continue» неактивна. Тап по карточке: неоновая фиолетовая обводка, галочка, искры, картинка чуть «подаётся» вперёд, вторая карточка отступает. Кнопка оживает.
2. **Шаг 2 · Who catches your eye?** Девушка в выбранном стиле крупно слева (видео-луп), справа колонка из четырёх миниатюр (картинки из Figma): Jade, Mia, Scarlett, Yuna; над верхней и под нижней — круглые кнопки-шевроны. Листать можно тапом по миниатюре, шевронами или свайпом по девушке. При каждой смене — бабл в одну строку с её фразой (над кнопкой, не доходит до миниатюр). «Choose her» сразу ведёт на шаг 3.
3. **Шаг 3 · Meet your match.** Камера переезжает к центру, и более крупное приветствие сменяет её луп (сначала совмещено с ней по масштабу и положению). Плашка с именем поднимается к логотипу, бабл с приветствием, кнопка «Start chatting». Любой тап ведёт на сайт EVA AI.

Отступы шапки идут по группам: логотип; заголовок с подзаголовком (14 px между ними); на шаге 2 — имя девушки отдельной группой (36 px).

Склейки (подобрано покадрово по самим роликам, таблицы в начале [src/game.js](src/game.js)):
- лупы переходят сами в себя в точках, где поза совпадает лучше всего (`LOOPS`);
- переход к приветствию — движение камеры (`FRAME`, `GREET_MATCH`) с лёгкой дымкой;
- при смене девушки уходящая просто гаснет, а новая мягко въезжает с той стороны, откуда её листнули (по вертикали для миниатюр и шевронов, по горизонтали для свайпа).

Тексты, реплики девушек и ссылка — в [src/config.js](src/config.js). Реплики короткие, в одну строку; если на каком-то устройстве строка всё же не влезает, шрифт бабла сам уменьшается. Края экрана слева и справа мягко уходят в цвет фона (`#shadeSide`), так что на экранах шире 9:16 у полей не видно шва. Дисклеймера нет, но низ экрана (y 1720–1920) оставлен свободным под него. Звук — только лёгкие UI-звуки (WebAudio, `sound` в конфиге); у роликов звука нет, кнопки звука нет.

## Сборка

```bash
npm run build                                   # -> dist/index.html (один файл, ~4,6 МБ)
node tools/build.mjs --url=https://evaapp.example
```

## Ассеты

```bash
python tools/prepare_assets.py                  # ролики + картинки + src/clips.js
python tools/prepare_assets.py --only video --slots _greet   # только часть роликов
```

Ролики берутся из `src/EVA AI Playable Ads #2/`. В игре используются 16: луп каждой девушки (шаг 2) и её приветствие (шаг 3), в двух стилях. Ролики шага 1 (луп и поцелуй Jade) и реакции «choose me» в сборку не входят: карточки статичные, а «Choose her» ведёт сразу к приветствию. Каждый ролик режется до того, что реально видно на экране:
- шаг 2 — кадр шириной во весь экран (девушка слева, ближе к миниатюрам), 596 px (показывается ×1,3);
- шаг 3 — кадр без низа под кнопкой, 600 px.

Кодирование: лёгкое шумоподавление (`hqdn3d`), x264 `veryslow`, `aq-mode=3`, CRF 32. Ролики встраиваются base64 (+33% к весу); весь `dist/index.html` ~4,6 МБ. Скрипт сам пишет `src/clips.js`: файл каждого ролика и какую часть исходного кадра 1090×1920 он содержит — по этим координатам игра его и размещает.

Картинки — из `figma-src/` (девушки, вырезанные в Figma, оба стиля): скрипт рисует карточки шага 1 и миниатюры шага 2 так, как они стоят в макете (с розовым свечением за девушкой); фиолетовый фон и скошенная форма — SVG по пути из Figma. Аниме-миниатюр в макете нет: они кадрируются как реалистичные (та же высота фигуры и положение головы). Миниатюры же служат аватарами в чате.

## Разработка

```bash
npm run dev            # http://localhost:8765/src/index.html (и /dist/index.html)
```

Для QA: `?s=2&st=anime` сразу открывает шаг 2 (стиль `real` или `anime`), `?s=3&st=real&g=1` — шаг 3 с девушкой номер `g` (0 Jade, 1 Mia, 2 Scarlett, 3 Yuna).

## Структура

- `src/` — игра; `src/fit.js` вписывает сцену в экран до разбора тяжёлых встроенных ресурсов; `src/ad.js` — адаптер сетей: MRAID (AppLovin, Unity, Vungle…), ironSource `dapi`, Mintegral, Google `ExitApi`, Meta `FbPlayableAd`, иначе `window.open`
- `dist/index.html` — готовый файл для загрузки в сеть
