# EVA AI — плейабл «What Will You Reply?»

Портретная мини-игра в пропорциях фрейма Figma (1080×1920): лёгкий флирт с Майей в формате чата, две развилки по два ответа. Без фреймворков: HTML + CSS + JS (Web Animations API, WebAudio).

Сцены играют ролики аниматора (папка `src/EVA AI Playable Ads #3/`); где в ролике есть голос, берётся версия со звуком. Звук включён по умолчанию, в правом верхнем углу кнопка, которая его выключает и включает. Там, где автоплей со звуком разрешён (обычно в SDK рекламных сетей), голос слышен сразу; где браузер запрещает звук до касания, ролики идут без звука (кнопка всё равно показывает «вкл»), и голос появляется с первым касанием в любом месте.

0. **S0 · Старт.** `intro` (луп) — «тсс», палец у губ, подмигивание; над кнопкой строка «Maya has a little secret for you» (мягко «дышит») и кнопка «Listen to Maya». Любой тап запускает чат, и этот же тап открывает звук, поэтому голос слышен уже с хука. Хук стартует в ближайший момент, когда «тсс» возвращается в позу начала хука (не дольше 1,3 с, иначе мягкий переход с дымкой). На широких сценах (старт, хук, первая реакция) кадр поднят на 140 px, чтобы голова была сразу под логотипом; на «good girl» камера плавно опускается вместе с наездом (`LIFT`).
1. **S1 · Hook.** `hook` — убирает прядь за ухо и говорит «Can I be your little secret… the one you only open late at night?»; дальше `idle1` (луп), пока не выбран ответ. Сообщение остаётся до выбора. Варианты: «Depends. Are you going to behave?» и «My phone is locked. But for you… maybe.»
2. **S2 · Реакция.** Выбранный вариант вспыхивает неоново-фиолетовым, оба уходят. `behave` — приподнятая бровь; `maybe` — тихий смех и наклон к камере. Реплика: «Mmm… only if you ask nicely 😏» / «Haha… lucky me 😉».
3. **S3 · Напряжение.** `tension` — камера приближается до «грудь и лицо», голос: «Now tell me… should I be a good girl tonight, or show you what I’m really thinking?»; дальше `idle2` (луп). Варианты: «Show me your bad side.» и «Tease me first. Then let go.»
4. **S4 · Payoff.** `bad` — пристальный взгляд; `tease` — пальцы у ключицы. Реплика: «Careful what you wish for… 🔥» / «Patience… I’m worth it 💋».
5. **S5 · CTA.** `final` — подбородок на руке, голос: «It’s past midnight…»; дальше `cta` (луп) и пульсирующая кнопка «Chat with Maya». С начала этой сцены любой тап ведёт в стор/на лендинг.

Как спрятаны склейки (всё в начале [src/game.js](src/game.js), подобрано покадрово по самим роликам):
- кроссфейды на запасных слоях `<video>`, звук уходящего ролика затухает вместе с картинкой;
- лупы переходят сами в себя в точках, где поза совпадает лучше всего (`LOOPS`);
- выбор во время лупа запускает реакцию в ближайший момент, когда поза в лупе совпадает с первым кадром реакции (`WIN`, но не дольше 2 с); выбор во время ролика с голосом ждёт его конца, фразы не обрываются;
- где у соседних роликов разная крупность (после смеха, после «good girl», перед «midnight»), следующий ролик стартует с зумом/сдвигом под последний кадр предыдущего и плавно доезжает до своего кадра, как движение камеры (`JOIN`);
- где отличается ещё и поза (смех → «good girl», ключица → «midnight»), в середине кроссфейда лёгкая дымка, чтобы не было двоения.

Дисклеймер пока скрыт, место под ним сохранено. Картинка отступает от краёв сцены на 2 px: слои видео композитятся и обрезаются по краю иначе, чем затемнения поверх них, и при дробном масштабе экрана крайний столбец видео оставался незатемнённым (светлая полоска по бокам).

Раскладка: варианты и кнопка CTA растянуты на всю ширину контента (x 36–1044, от левого края аватарки до правого края бабла, поля по 36 px), бабл заканчивается на том же правом крае, а нижний край во всех сценах на одной линии (y 1730), ровно в 32 px над дисклеймером, поэтому блоки не скачут (`LINE` и `GAP` в [src/game.js](src/game.js)).

## Сборка

```bash
npm run build                                   # -> dist/index.html (один файл)
node tools/build.mjs --url=https://landing.example
```

Все тексты, дисклеймер (пока заглушка из прошлого плеебла, 18 px) и ссылка — в [src/config.js](src/config.js). `sound: false` — старт без звука (включается только кнопкой).

## Видео

```bash
python tools/prepare_assets.py --only video     # 720 px, H.264 CRF 33 (veryslow), голос — моно AAC 48k
```

Берёт ролики из `src/EVA AI Playable Ads #3/` (какой файл в какой слот — `DELIVERY` в [tools/prepare_assets.py](tools/prepare_assets.py)) и кладёт в `src/video/<слот>.mp4`; слоты прописаны в [src/clips.js](src/clips.js). Файл `src/animations/<слот>.mp4`, если есть, важнее поставки. Версии «_sound» — отдельные дубли с движением губ, поэтому цепочка собрана из них (в т. ч. финальный луп `Step_4-2_idle loop_sound`, у него нет звуковой дорожки, но он продолжает голосовой «midnight»). Если ролики заменят, точки `LOOPS`, `WIN` и `JOIN` нужно подобрать заново.

Размер: весь `dist/index.html` держим до 5 МБ (сейчас ~4,94 МБ; ролики встраиваются base64, это +33% к их весу). Чтобы влезть без видимой потери: лёгкое шумоподавление (`hqdn3d`) убирает собственный шум сжатия исходников, x264 `veryslow` с одним ключевым кадром на ролик, `aq-mode=3` (без бандинга на тёмно-фиолетовом градиенте фона), CRF 33. Если ролики добавятся, бюджет придётся пересчитать (`--crf` у скрипта).

## Ассеты

```bash
python tools/prepare_assets.py --only images
```

Постер (`src/assets/poster.webp`) — первый кадр `intro`, он лежит под видео, пока первый кадр не декодирован. Аватар чата (`maya_ava.webp`) — её лицо из первого кадра `idle2`. Шрифт General Sans (Fontshare, ITF Free Font License) встроен.

## Разработка

```bash
npm run dev            # http://localhost:8765/src/index.html (и /dist/index.html)
```

`tools/serve.mjs` — статический сервер с поддержкой Range-запросов (без них браузер не перематывает видео).

Для QA: `?s=hook` пропускает старт, `?s=tension` сразу открывает второй вопрос, `?s=end` — финальный экран.

## Структура

- `src/` — игра; `src/fit.js` вписывает сцену в экран ещё до разбора тяжёлых встроенных ресурсов (до этого сцена скрыта); `src/clips.js` — слоты роликов; `src/ad.js` — адаптер сетей: MRAID (AppLovin, Unity, Vungle…), ironSource `dapi`, Mintegral, Google `ExitApi`, Meta `FbPlayableAd`, иначе `window.open`
- `dist/index.html` — готовый файл для загрузки в сеть
