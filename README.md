# EVA AI — плейабл «Choose My Look»

Портретная мини-игра в пропорциях фрейма Figma (1080×1920) на видеороликах от аниматора. Без фреймворков: HTML + CSS + JS (Web Animations API, WebAudio).

1. **Привет.** Зацикленное видео Руби, логотип, плашка «Ruby • AI character», входящее сообщение «Hi! I'm Ruby!» (сначала точки набора, потом бабл с пингом) и пульсирующая кнопка «Tap to start».
2. **Выбор платья.** Видео плавно переходит в луп ожидания, заголовок «Tap dress to choose» проявляется целиком и «дышит» (лёгкий масштаб и свечение), Руби спрашивает, какое платье надеть, снизу выезжают три карточки и кнопка «Try it on» — сначала неактивная. Все три платья равнозначны, ни одно не выделяется. Выбранная карточка становится неоново-фиолетовой с галочкой в углу, остальные приглушаются, кнопка включается.
3. **Примеряет и поворачивается.** Карточки, кнопка и текст уходят вместе, картинка расплывается и светлеет, на пике этой дымки под ней меняется наряд, вспыхивают искры, и картинка снова становится чёткой. «It looks amazing on me…» и «…but the zipper's stuck in the back. Care to help?» приходят, пока она себя разглядывает, затем ролик с поворотом.
4. **Молния.** Луп спиной не используется: конец поворота почти совпадает с первым кадром ролика с молнией, поэтому, развернувшись, она плавно переходит в этот кадр и неподвижно ждёт свайпа. Сообщения уходят, появляются заголовок «Swipe down to unzip», пунктир со стрелкой вдоль молнии и рука, которая показывает свайп. Палец задаёт цель, а кадр ролика и бегунок молнии плавно догоняют её с ограниченной скоростью: медленный свайп идёт сразу за пальцем, резкий не проскакивает, а доигрывается за полсекунды. На каждый «зубчик» щелчок молнии. Молния останавливается, не расстегнувшись до конца, ролик ещё мгновение играет её реакцию. Короткий свайп пружинит назад, после 40 % дотягивается сам.
5. **Чат.** Быстрая склейка через затемнение в тёмный чат: «Ruby • Online now», финальное сообщение и пульсирующая «Reply to Ruby». Любой тап ведёт в стор/на лендинг.

Стыки между роликами — кроссфейды на запасных слоях `<video>` (их четыре). Точки склейки подобраны покадрово (`SEAM` и `LOOPS` в [src/game.js](src/game.js)): каждый ролик переходит в следующий там, где кадры совпадают лучше всего, а лупы прыгают не «конец → начало», а между самыми похожими кадрами. Если на первом экране тапнуть, пока Руби поправляет волосы, интерфейс меняется сразу, а видео дожидается точки петли и переходит бесшовно.

У кнопок два полупрозрачных контура вокруг — это и есть волны: на каждый такт кнопка слегка «вздыхает», и из-под неё одна за другой выходят две волны, которые расходятся на одинаковое расстояние со всех сторон (двигаются границы, а не масштаб) и гаснут.

## Сборка

```bash
npm install
npm run build                                   # -> dist/index.html (один файл, ~8.4 MB)
node tools/build.mjs --url=https://landing.example
```

Все тексты и ссылка — в [src/config.js](src/config.js). `sound: false` выключает звуки интерфейса.

## Ассеты

```bash
npm run assets                                        # ролики 720 px, CRF 29 + картинки
python tools/prepare_assets.py --width 540 --crf 31   # влезает в лимит сетей 5 MB, но мягче
python tools/prepare_assets.py --only images
```

- `src/animations/*.mp4` — ролики аниматора: `1-<сцена> - Choose My Look - <платье>` (сцена 1 интро / выбор, 2 примеряет, 3 поворот, 4 луп спиной — не используется, 5 молния, 6 финал; платье 1 красное, 2 чёрное, 3 бордовое).
- `tools/prepare_assets.py` перекодирует их в `src/video/` (H.264, без звука). Ролик молнии обрезан до 3 с и с ключевым кадром каждые 6 кадров, чтобы палец плавно его перематывал. Там же кадр-постер, обрезка платьев, аватар Руби и чистый SVG логотипа из `figma-src/`.
- Где молния на каждом ролике спиной — `ZIP` в начале [src/game.js](src/game.js).
- Шрифт General Sans (Fontshare, ITF Free Font License) встроен.

## Разработка

```bash
npm run dev            # http://localhost:8765/src/index.html (и /dist/index.html)
```

`tools/serve.mjs` — маленький статический сервер с поддержкой Range-запросов: без них браузер не перематывает видео.

Для QA: `?d=red|black|burgundy` сразу открывает свайп в этом платье, `&end=1` — финальный чат.

## Структура

- `src/` — игра; `src/clips.js` — список роликов, `src/ad.js` — адаптер сетей: MRAID (AppLovin, Unity, Vungle…), ironSource `dapi`, Mintegral, Google `ExitApi`, Meta `FbPlayableAd`, иначе `window.open`
- `dist/index.html` — готовый файл для загрузки в сеть
