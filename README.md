# JugaBet — Pepper Piñata playable

Портретная мини-игра (пропорции фрейма Figma 1089×1920), концепт «Pepper Piñata (Destruction)».

1. Пиньята-халапеньо покачивается на верёвке. Внизу панель с оружием: бита, клюшка и молот. Рука с кольцами на каждом нажатии подсказывает выбор, оружие по очереди подпрыгивает.
2. Выбранный слот загорается зелёным с золотой рамкой и искрами. Оружие одним плавным движением по дуге перелетает из слота в руку слева, его свечение (мягкий свет и золотая пыль) летит вместе с ним, панель уезжает вниз, появляется «¡Toca para smash!».
3. Четыре удара. Оружие замахивается и бьёт, пиньята отлетает и раскачивается на верёвке, экран вздрагивает, летят искры и кусочки бумаги. Новая трещина расползается от точки удара, светится и потрескивает. Подпись меняется: «¡Dale otra vez!», «¡Más fuerte!», «¡Un golpe más!».
4. Четвёртый удар: вспышка, пиньята лопается и остаётся в последнем стейте с высыпающимися монетами, часть монет выбивает вверх, остальные высыпаются вниз, отскакивают от брусчатки и поблёскивают, летит конфетти. Затем появляется поп-ап «TU BONO: 125 GIROS GRATIS» с монетами, лучами, звёздочками и конфетти, и кнопка «RECLAMAR BONO».

Без фреймворков: HTML + CSS + JS (Web Animations API, частицы на одном canvas).

## Сборка

```bash
npm install
npm run build                                   # -> dist/index.html (один файл, ~1.2 MB)
node tools/build.mjs --amount=125 --unit="giros gratis" --url=https://landing.example
```

Параметры кампании и все тексты (испанский) лежат в [src/config.js](src/config.js): `bonusAmount`, `bonusUnit`, `clickUrl`, `locale`, `text` (заголовок, подписи после каждого удара, поп-ап, кнопка).
Флаги `--amount`, `--unit`, `--url` переопределяют их при сборке. Длинные тексты автоматически ужимаются по ширине (`data-max` в разметке).

## Разработка

```bash
npm run dev            # http://localhost:8765/src/index.html
```

Для QA: `?w=0..2` сразу выбирает оружие (бита, клюшка, молот), `&auto=1` сам наносит удары, `?end=1` сразу открывает поп-ап с бонусом.

## Структура

- `figma-src/` — исходники из Figma (как есть)
- `tools/prepare_assets.py` — нарезка и сжатие в WebP:
  - стадии трещин пиньяты превращаются в слои поверх целой пиньяты, чтобы трещина расползалась от точки удара, а не подменялась картинкой;
  - из горящих трещин собирается отдельное свечение;
  - у золотой пыли чёрный фон заменяется на прозрачность;
  - к руке-указателю добавляется тень;
  - из картинки взрыва вырезаются отдельные монеты (`coin.webp`): из них сделаны летящие монеты, поэтому они в том же стиле, что и арт.
- Панель оружия и кнопка нарисованы в CSS: панель в Figma — цельная картинка с впечатанным оружием, а кнопка — растянутый маленький битмап.
- `src/` — игра; `src/ad.js` — адаптер сетей: MRAID (AppLovin, Unity, Vungle…), ironSource `dapi`, Mintegral, Google `ExitApi`, Meta `FbPlayableAd`, иначе `window.open`
- `dist/index.html` — готовый файл для загрузки в сеть
